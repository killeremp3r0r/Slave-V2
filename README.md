# Slave — PC Check Tool

Developed by **KillerEmperor** · Windows · Python 3.9+ · UI languages: TR / EN / RU / UK

Slave is a local desktop tool for checking a Windows PC for known cheat/executor software and reviewing system traces. It includes Browse, Data Usage, Traces, DLL / Memory, Launch History, USN File Traces, Unsigned EXEs, Private Memory, and Risk Score tools.

A name or behavior match is a lead for manual review, not proof of cheating. Review the file, process, and surrounding evidence before drawing conclusions.

## What it does (and does not do)

- Scans and analysis run locally. Slave does not upload scan results and has no telemetry.
- **Browse Tool** searches file names with Everything. It requires Everything to be installed separately and running, with either `es.exe` beside `slave.py` or Everything’s HTTP Server enabled at `127.0.0.1:8080`. Neither Everything nor `es.exe` is included in the Slave release.
- **Data Usage** reads Windows SRUM application network and disk usage history.
- Other tools read local Windows traces and, for Roblox-specific checks, Roblox process memory while Roblox is running. Some checks need administrator access.
- Settings are saved to `slave_config.json` beside the app.
- Optional appearance features use Pillow. The loading sound is generated by the app and cached in your temporary folder.
- The passcode screen is a community gate, not security. The source is open; read it.

## Requirements

- Windows 10 or 11 (64-bit)
- Python 3.9+ with `tkinter`
- Python packages listed in `requirements.txt`
- Optional: Everything from [voidtools.com](https://www.voidtools.com/) for the Browse Tool. Install `es.exe` separately if using that integration; alternatively enable Everything → Options → HTTP Server on port 8080.

## Install & run

1. Download and extract the Slave V2 release. Everything and `es.exe` are not part of the release.
2. Install Python 3.9+ if needed, and select the option to add Python to PATH.
3. Double-click `Setup.bat` to install the Python packages.
4. Double-click `Run as administrator.bat` for the system trace and process analysis features, then approve the Windows prompt.
5. Enter the passcode and choose your nickname. The nickname is stored locally in `slave_config.json`.

You can also start the app without elevation by running `python slave.py` in the application folder. Some system checks may then show incomplete results due to Windows access restrictions.

### Set up Browse Tool (optional)

1. Install and run Everything from [voidtools.com](https://www.voidtools.com/).
2. Either download the Everything command-line tool `es.exe` separately and place it next to `slave.py`, or enable Everything → Options → HTTP Server (port 8080).
3. Use Browse Tool in Slave. The other tools do not require Everything.

## Configs

Each tool has its own config list. **Default** is built in and cannot be edited. Use *Create new* to make a list, *Edit list* to change it, and *Delete* to remove it.

## Appearance

Use the brush button in the header to choose color presets, a background image with blur, and interface opacity. Pillow is installed by `Setup.bat` and supports optional image features.
